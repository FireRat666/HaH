Holograms Against Humanity

A terrible game for terrible people: a synced multiplayer Cards Against Humanity clone for up to 10 players. Everything runs client-side in the space, so it needs only static hosting. Made for SideQuest / AltspaceVR worlds, and it also works in Banter.

There is no server: players stay in sync through the space's shared state, and the game is plain static files served from hah.firer.at.

2a. Add it in Unity

You need a Unity project with the Altspace / Banter Creator SDK already set up, and your world's scene open.

  1. Make an empty object. In the top menu choose GameObject › Create Empty. Rename it to Holograms Against Humanity so you can find it later (the object's name doesn't matter, only the slug does).
  2. Put it at the middle of the world. With the new object selected, look at Transform in the Inspector and set Position to 0 0 0 and Rotation to 0 0 0. Why: you don't move the game by moving this object. You move it with the snippet's own position and rotation settings (step 6). If the object (or anything it's inside) isn't at 0 0 0, the SDK's gizmos won't line up with where it really appears.
  3. Add the Snippet component. Click Add Component, type Snippet in the search box, and pick BS › Snippet.
  4. Type the slug and press Enter. In the Snippet's Slug box type and press Enter (the box only takes it after Enter or clicking somewhere else). It downloads the snippet and adds it to your world's Assets/WebRoot/index.html for you. After a moment the Inspector shows the title Holograms Against Humanity and a list of settings. If nothing happens, click Refresh from server.
  5. Save the scene. Press Ctrl + S (Windows / Linux) or Cmd + S (Mac). Do this every time you add or remove a snippet. Closing Unity without saving is the main way extra copies of the snippet end up in index.html.
  6. Place and configure it. Change the settings in the Inspector, or drag the gizmo handle in the Scene view to move it. All settings are listed on GitHub.
  7. Upload your world the same way you always do, then join it in Altspace to play.

Multiple copies in one world: you can add more than one Holograms Against Humanity snippet. In Unity each placement automatically gets its own separate game state unless you set the same room name on both.

2b. Add it on the website

  1. Open your world for editing on altvr.app and go to the Snippets section.
  2. Find Holograms Against Humanity. Set the list to show All snippets, then search for Holograms Against Humanity (or scroll to it) and open it.
  3. Copy it. Click Copy & open index.html. This copies the snippet's code and opens your world's HTML (or copy the full snippet code below).
  4. Paste it in the right place. If your HTML has these two lines, paste between them: 
    <!-- snippet section -->
   paste here
<!-- end snippet section -->
    If it doesn't have them, paste it just before </body>.
  5. Change the settings by editing the values in quotes in the pasted code, for example position="0 0 3". If you paste more than one copy, give each one its own room (like room="table-1" and room="table-2") so they stay separate.
  6. Save, then join your world to play.

Keep the code tidy. Every value needs quotes around it (sound-volume="0.4", not sound-volume=0.4), and a & in any link must be written as &amp;. Unity reads this part strictly, and one mistake can break the whole snippet section.

The full snippet code

This is everything the snippet adds, with every setting at its default. Click the code to copy it.

Full snippet code
<!-- snippet section -->
<bs-snippet name="hah" title="Holograms Against Humanity"
  description="Synced multiplayer party card game table."
  script="https://hah.firer.at/snippet.js"
  room=""
  position="0 0 3"
  rotation="0 0 0"
  cull-distance="20"
  sound-volume="0.4"
  sound-near="2.5"
  sound-far="10"
  debug="false">
  <bs-gizmo type="position" attribute="position"/>
  <bs-gizmo type="plane" attribute="position" size="3.2 3.2" rotation="90 0 0"/>
</bs-snippet>
<!-- end snippet section -->

2c. Banter (or manual): add it with a script tag

Paste this into a Banter space's HTML, or into an Altspace world's Assets/WebRoot/index.html (outside the snippet section). Give each copy its own instance to have more than one game in a space.

Script tag
<script src="https://hah.firer.at/hah.js" position="0 -0.4 -5" instance="my-private-game"></script>

All the settings are listed on GitHub.

Features

  • More than 70 official and unofficial packs from the JSON Against Humanity card database & spreadsheet (also available via the CAH Serverless API), chosen by the host in game
  • Players can rejoin a game in progress and keep their seat
  • If the host leaves, another player takes over as host after a few seconds, so timers and turns keep going
  • Switches itself off when you are far from the table, and back on when you return

How to play

The game starts with the CAH Base Set. The host (or anyone who claims host in an empty room) can change it:

  1. Click DECK OPTIONS on the centre hub.
  2. Click packs to turn them on or off (green is on).
  3. Click SAVE DECKS.
  4. Click START ROUND.

Synced multiplayer party card game table. Open hah.firer.at as a space in Altspace or Banter to try it.
