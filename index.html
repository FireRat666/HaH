Holograms Against Humanity

A terrible game for terrible people: a synced multiplayer Cards Against Humanity clone for up to 10 players. Everything runs client-side in the space, so it needs only static hosting. Made for SideQuest / AltspaceVR worlds, and it also works in Banter.

There is no server: players stay in sync through the space's shared state, and the game is plain static files served from hah.firer.at.

Add it to an Altspace world

  • On the website: edit your world on altvr.app, open Snippets on the left, choose All, then pick Holograms Against Humanity.
  • In Unity: add an empty GameObject, click Add Component > BS > Snippet and type hah.

Add it with a script tag

Paste this into a Banter space's HTML, or into an Altspace world's Assets/WebRoot/index.html (outside the snippet section). Give each copy its own instance to have more than one game in a space.

Script tag
<script src="https://hah.firer.at/hah.js" position="0 -0.4 -5" instance="my-private-game"></script>

All the settings are listed on GitHub.

Features

  • More than 70 official and unofficial packs from the JSON Against Humanity card database & spreadsheet (also available via the CAH Serverless API), chosen by the host in game
  • Players can rejoin a game in progress and keep their seat

How to play

The game starts with the CAH Base Set. The host (or anyone who claims host in an empty room) can change it:

  1. Click DECK OPTIONS on the centre hub.
  2. Click packs to turn them on or off (green is on).
  3. Click SAVE DECKS.
  4. Click START ROUND.

Synced multiplayer party card game table. Open hah.firer.at as a space in Altspace or Banter to try it.
